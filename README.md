# 図面計測ツール

PDF・画像の図面から、2点間距離・連続線・面積・円弧を計測し、壁面積の集計とボード割付図（展開図）を作成するWebアプリです。

**アプリを開く → https://030809240222im-star.github.io/zumen-keisoku/**

- 図面や計測データは、使う人の端末（ブラウザ）の中だけに保存され、外部には送信されません。
- iPhone：Safariで開き、共有ボタンから「ホーム画面に追加」を選ぶと、アプリのように使えます。一度開けばオフラインでも起動できます。
- 壁仕様のデータは、吉野石膏の公開カタログ・認定書一覧をもとにしています。施工の前に、必ずメーカーの最新資料で確認してください。
