# 公開と使用者の管理（管理者向け）

図面計測ツールは、**管理者が名簿に登録したメールアドレスの人だけ**が使えます（Firebase。無料プラン）。

- アプリのアドレス：<https://zumen-keisoku.web.app>（開くと自動で `zumen-keisoku.firebaseapp.com` に移ります）
- 図面と計測のデータは、使う人の端末の中だけに保存され、外には送りません。Firebase に置くのは、名簿とアプリ本体だけです。

## 使用者を追加する（管理者）

1. アプリに**管理者のメールアドレス**でログインします。
2. 上の列の **「👥 名簿」** を押します（管理者にだけ出ます）。
3. メールアドレスを入れて **「追加する」**。改行やカンマで区切れば、まとめて入れられます。
4. **「招待の文面をコピー」** を押し、LINE やメールに貼り付けて本人に送ります。

## 使用者がすること（はじめての1回）

1. アプリのアドレスを開きます。
2. **Google アカウントがある人**：「Google でログイン」。
3. **無い人**：「はじめての方（登録）」でメールアドレスとパスワードを決め、届いた確認メールのリンクを押してから「リンクを開いたので続ける」。

2回目からは、ログインしたまま開きます。「ホーム画面に追加」すると、アプリのように使えます。

## やめてもらう・管理者を増やす

- **外す**：名簿の「外す」。電波のある所でアプリを開いた時（開いたままなら30分以内）に使えなくなります。
- **管理者を増やす**：名簿の「役割」を「管理者」にします。管理者は名簿を直せます。
- 最初の管理者（持ち主）と自分自身は、外せません（締め出しを防ぐため）。

## 困ったとき

| 出たもの | 理由と直し方 |
|---|---|
| 「名簿に登録されていません」 | ログインしたメールアドレスが名簿に無い。綴りを確かめて追加 → 本人は「もう一度確かめる」 |
| 確認メールが届かない | 迷惑メールのフォルダを見る。「確認メールをもう一度送る」 |
| 「メールアドレスかパスワードが違います」 | はじめての人は「はじめての方（登録）」から。忘れたときは「パスワードを忘れたとき」 |
| 「つながりませんでした」 | 電波のある所で「もう一度試す」 |
| 「もう一度ログインしてください」 | 名簿から外れたか、ログインが切れた。管理者に確かめる |

## 守っていること・守れないこと

- **守っていること**
  - 誰でも見える所に置くのはログイン画面だけ。アプリ本体は、名簿の人だけが読める場所（Firestore）から渡す。
  - メールアドレスの確認が済んでいない人・名簿に無い人は、アプリ本体も名簿も読めない。
  - 名簿を直せるのは管理者だけ。アプリ本体は、画面からは誰も書き換えられない。
- **守れないこと**
  - 登録した人が、開いたアプリの中身を保存して持ち出すことは止められない。
  - 電波の無い端末では、最後に確かめてから30日まで、端末に残った控えで使えることがある。
  - ログインと名簿のため、Google（Firebase）との通信はある。
- 共用の端末では、「👤 アカウント」→「ログアウトして、この端末のデータを消す」を使う。

## 公開し直す（開発）

`node tools/fbdeploy.mjs`（組み立て → 公開 → 確認）。確認だけは `node tools/fbdeploy.mjs --check`。
管理者のメールは `firebase/local.json`（このパソコンだけ。git に入れない）に書く。
